# Insurance Website — Complete UI Design & Colour System

## 1. Overall Design Style

Create a modern, premium, warm, trustworthy insurance website.

The visual style should be:

* Clean
* Professional
* Modern
* Trustworthy
* Warm rather than overly corporate
* Spacious
* Rounded
* Minimal but visually rich
* Strong use of colour blocks
* Large typography
* Soft cards
* Clear visual hierarchy
* Smooth hover and transition effects

The website should NOT look like a generic banking dashboard.

Use a **modern editorial landing-page style** with large sections, strong colour backgrounds, rounded components, bold typography, and controlled use of accent colours.

# 3. Colour Hierarchy

Use the colours approximately like this:

```text
#FAF0BE  → Main background
#FFF8DC  → Cards and surfaces
#2B1810  → Main dark / text
#2E6B4E  → Trust / protection
#FF6F61  → Attention / CTA
#F7E9A8  → Highlight / dark-section text
#6B5546  → Secondary text
#C9B88A  → Dark-section secondary text
```

The most important rule:

**Do not use all colours equally.**

The visual hierarchy should be:

```text
Dark Brown
     ↓
Cream / Butter
     ↓
Green
     ↓
Coral
```

Coral should remain an accent, not dominate the entire website.

# 9. Card Design System

All normal cards should follow the same visual language.

## Card

```text
Background: #FFF8DC
Border: subtle #2B181026
Radius: 22–28px
Padding: 28–32px
```

## Hover

On hover:

* Move upward slightly: 3–5px
* Increase shadow slightly
* Border becomes slightly stronger
* Icon can change to coral
* Transition approximately 200–300ms

Do NOT make cards rotate or use excessive animations.

## Card shadow

Use soft shadows.

Avoid heavy black shadows.

# 25. Shadows

Use soft shadows.

Normal card:

```text
0 8px 24px rgba(43, 24, 16, 0.08)
```

Hover:

```text
0 14px 30px rgba(43, 24, 16, 0.12)
```

For selected/highlighted cards, a slightly stronger shadow is acceptable.

Avoid huge shadows.

---

# 26. Spacing

Use generous spacing.

Recommended:

```text
Section top/bottom:    80–100px
Desktop container:     max-width 1120–1200px
Horizontal padding:    24px
Card gap:              20–32px
Heading → paragraph:   16–24px
Paragraph → button:    24–32px
Card padding:          28–32px
```

The website should feel spacious rather than compressed.

---

# 27. Responsive Design

Desktop:

```text
3–4 cards per row
Two-column hero
Large typography
Full navigation
```

Tablet:

```text
2 cards per row
Reduced spacing
Smaller hero
```

Mobile:

```text
1 card per row
Single-column hero
Hamburger navigation
Full-width buttons where appropriate
Reduced heading size
Reduced section padding
```

Never allow horizontal scrolling.

---

# 28. Animation Style

Animations should be subtle.

Use:

* Fade-in
* Slight upward movement
* Smooth hover
* Card elevation
* Button colour transition
* Small icon movement

Animation duration:

**200–400ms**

Avoid:

* Excessive bouncing
* Rotating cards
* Large zoom effects
* Flashing colours
* Continuous distracting animations

# 30. Final Design Rule

The website should feel like:

**Trustworthy insurance + modern technology + human warmth.**

The colour roles must remain consistent:

```text
#2B1810
THE FOUNDATION
Dark / Trust / Typography / Navigation / Footer

#FAF0BE
THE MAIN BACKGROUND
Warm / Friendly / Spacious

#FFF8DC
THE SURFACE
Cards / Forms / Panels

#2E6B4E
THE TRUST COLOUR
Protection / Security / Positive states

#FF6F61
THE ATTENTION COLOUR
CTA / Hover / Important actions

#F7E9A8
THE HIGHLIGHT
Dark-section text / Navigation / Accents

#6B5546
THE SUPPORT COLOUR
Paragraphs / Secondary information

#C9B88A
THE DARK-SURFACE SUPPORT COLOUR
Footer / Dark-section secondary text
```

**Most important:** Keep the background mostly light, keep dark brown for strong structural areas, use green to communicate trust, and reserve coral for actions that you want users to notice.

The result should look **premium, warm, trustworthy, modern, and highly consistent**, rather than colourful for the sake of being colourful.
